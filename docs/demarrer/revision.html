Qu’est-ce qu’un réseau ? — Des machines qui échangent des messages

Un réseau, ce sont des appareils reliés entre eux et des règles communes pour s’échanger des messages.

  • Un réseau = des appareils, des liaisons (câble, fibre, ondes) et des règles communes (les protocoles).
  • Un réseau local (LAN) couvre une maison ou un bâtiment ; Internet relie des millions de réseaux entre eux.
  • Chaque échange suit le même principe — un émetteur, un destinataire, un message avec une adresse.

Les équipements — Switch, routeur, point d’accès, pare-feu

Le switch relie les appareils d’un même lieu, le routeur relie des réseaux entre eux, le point d’accès remplace le câble par des ondes et le pare-feu filtre.

  • Le switch relie les appareils d’un même réseau local.
  • Le routeur relie des réseaux différents — c’est la porte de sortie vers Internet.
  • Le point d’accès Wi-Fi remplace le câble par des ondes ; le pare-feu décide quels échanges sont autorisés.
  • Une box Internet réunit tous ces rôles dans un seul boîtier.

Un message en paquets — Découper, emballer, déballer

Un message est découpé en petits morceaux, et chaque morceau est emballé dans plusieurs enveloppes successives, chacune lue par un équipement différent.

  • Un gros message est découpé en paquets de 1 500 octets environ, qui voyagent indépendamment.
  • Chaque paquet est emballé dans plusieurs enveloppes (les en-têtes) — c’est l’encapsulation.
  • Chaque équipement ne lit que l’enveloppe qui le concerne — le switch lit l’adresse MAC, le routeur l’adresse IP.

Les adresses et les règles

Les trois adresses — Nom, adresse IP, adresse MAC

Un appareil se désigne de trois façons — un nom pour les humains, une adresse IP pour trouver son réseau dans le monde, une adresse MAC pour le livrer sur le réseau local.

  • Le nom (www.exemple.fr) est pour les humains ; le DNS le traduit en adresse IP.
  • L’adresse IP (192.168.1.20) indique le réseau et la machine ; les routeurs l’utilisent pour acheminer le paquet.
  • L’adresse MAC (3c:22:fb:1a:09:7e) identifie la carte réseau ; le switch l’utilise pour livrer sur le réseau local.

Les protocoles — Des règles communes et des numéros de port

Un protocole est un ensemble de règles que deux appareils suivent pour se comprendre ; le numéro de port indique à quel service un message est destiné.

  • Un protocole fixe le format des messages et l’ordre des échanges.
  • Les protocoles s’empilent — Ethernet pour le local, IP pour le chemin, TCP ou UDP pour le transport, puis le protocole de l’application (HTTP, DNS…).
  • Le numéro de port désigne le service visé sur la machine — 443 pour un site Web sécurisé, 53 pour le DNS.

Ma box et Internet — Le voyage d’une page Web, de bout en bout

Pour afficher une page, ton ordinateur obtient une adresse, traduit le nom du site, envoie la demande à sa box, qui la fait suivre de réseau en réseau jusqu’au serveur.

  • Au démarrage, l’appareil reçoit de la box (DHCP) son adresse IP, sa passerelle et son serveur DNS.
  • Le DNS traduit le nom du site ; la passerelle fait sortir la demande vers Internet.
  • La box traduit les adresses (NAT) — tous les appareils de la maison partagent une seule adresse IP publique.

Passer à la pratique

Les commandes de base — ipconfig, ping, tracert, nslookup

Quatre commandes, disponibles sur tous les ordinateurs, suffisent à savoir où une connexion échoue.

  • ipconfig /all (Windows) ou ip a (Linux) — ai-je une adresse, une passerelle et un DNS ?
  • ping — est-ce que j’atteins cette machine ?
  • tracert / traceroute — par où passe le chemin, et où s’arrête-t-il ?
  • nslookup — le nom est-il traduit en adresse IP ?
