Huit repères pour comprendre ce qu’est un réseau, sans aucun prérequis. Compte une heure en tout.

Commencer iciFaire le quiz du débutant

1

Le décor

Ce qu’est un réseau, avec quels appareils, et comment un message voyage.

  • BienvenueNexorya t’emmène du tout premier câble jusqu’au datacenter, une notion à la fois, en expliquant toujours le pourquoi avant le comment.
  • Qu’est-ce qu’un réseau ?Un réseau, ce sont des appareils reliés entre eux et des règles communes pour s’échanger des messages.
  • Les équipementsLe switch relie les appareils d’un même lieu, le routeur relie des réseaux entre eux, le point d’accès remplace le câble par des ondes et le pare-feu filtre.
  • Un message en paquetsUn message est découpé en petits morceaux, et chaque morceau est emballé dans plusieurs enveloppes successives, chacune lue par un équipement différent.
2

Les adresses et les règles

Comment les machines se trouvent et se comprennent.

  • Les trois adressesUn appareil se désigne de trois façons — un nom pour les humains, une adresse IP pour trouver son réseau dans le monde, une adresse MAC pour le livrer sur le réseau local.
  • Les protocolesUn protocole est un ensemble de règles que deux appareils suivent pour se comprendre ; le numéro de port indique à quel service un message est destiné.
  • Ma box et InternetPour afficher une page, ton ordinateur obtient une adresse, traduit le nom du site, envoie la demande à sa box, qui la fait suivre de réseau en réseau jusqu’au serveur.
